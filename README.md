
# Digital Budget Telegram Bot

Telegram bot for automating digital advertising analytics and reporting.

## Description

This project helps automate the collection, processing, and analysis of digital advertising data.

## Features

- Digital advertising data processing
- Integration with external APIs
- Automated analytical reports
- Telegram bot interface
- AI-assisted analytics

## Tech Stack

- Python
- Pandas
- SQL Server
- Telegram Bot API
- DeepSeek API

## Project Structure

- `main.py` — Main application
- `OpenAI.py` — AI integration
- `config.py` — Configuration management

## Security

API keys and sensitive configuration are stored in environment variables and are not included in the repository.

## Status

Project under development.
